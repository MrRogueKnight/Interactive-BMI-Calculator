# Interactive BMI Calculator

This project is a user-friendly and **interactive Body Mass Index (BMI) calculator** designed for quick and easy health assessment. Built using fundamental web technologies, it allows users to input their weight and height, instantly receive their calculated BMI, and understand their corresponding BMI classification (e.g., Underweight, Healthy, Overweight, Obese). The interactive nature of this tool provides immediate feedback, making health tracking straightforward and engaging.

### ✨ Features:

  * **Dynamic & Real-time Calculation:** Instantly calculates and displays BMI as you input your data.
  * **Intuitive User Interface:** A clean, responsive design for a seamless experience on any device.
  * **Gender Selection:** Allows for a personalized display, acknowledging gender (though BMI calculation itself is generally gender-neutral).
  * **Light/Dark Mode Toggle:** Customize your viewing preference for enhanced readability.
  * **Clear Classification:** Provides immediate categorization of your BMI (e.g., "Healthy," "Overweight") for easy understanding.
  * **Responsive Design:** Optimized for a consistent experience across desktops, tablets, and mobile phones.

### 🚀 How to Use:

1.  **Enter your Weight:** Input your weight value in kilograms (kg).
2.  **Enter your Height:** Input your height value in centimeters (cm).
3.  **Select your Gender:** Choose between Male or Female.
4.  **View Results:** Your BMI and its classification will automatically update and display below the input fields.
5.  **Toggle Theme (Optional):** Click the "Toggle Light/Dark Mode" button to switch between themes.

### 🛠️ Technologies Used:

  * **HTML5:** Provides the structural foundation of the web application.
  * **CSS3:** Styles the application, ensuring a modern and visually appealing interface.
  * **JavaScript (ES6+):** Powers the core BMI calculation logic, interactive elements, and theme toggling functionality.

### 📦 Installation & Setup:

This is a client-side web application, requiring no complex backend setup or database.

1.  **Clone the repository to your local machine:**
    ```bash
    git clone https://github.com/MrRogueKnight/Interactive-BMI-Calculator.git
    ```
2.  **Navigate into the project directory:**
    ```bash
    cd Interactive-BMI-Calculator
    ```
3.  **Open `index.html`:** Simply open the `index.html` file in your preferred web browser to launch the BMI calculator.
